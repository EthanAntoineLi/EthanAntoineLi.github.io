01 / The assistant

What she actually does.

Built around my needs

  1. Long-term memory

    Context carries across sessions; a project or a reminder is picked up later, not explained again.

  2. Reminders

    A sentence becomes a timed nudge. She comes back when it’s due.

  3. Morning timetable

    My timetable arrives every morning.

  4. Practice questions

    Topic-specific questions from my question bank, drafted by a dedicated question-maker sub-agent; the main agent wakes it when needed.

02 / The build

A framework, and
everything around it.

Layered, not monolithic

OpenClaw is the base framework — the agent machinery that already existed. I built the layers on top: memory, reminders, the timetable, the question bank.

Work that needs its own focus gets a specialist sub-agent; the main agent decides when to wake it. Nora runs on a dedicated Mac — the whole machine is hers, not an app I open.

03 / The interface

An agent needs
a face.

160 × 90 px · 15 fps

An always-on assistant is invisible when it’s working. The cat makes the state readable from across the room: what she’s doing, and whether she’s even there.

  • Offline asleep in a cardboard box; the room dims
  • Idle blinks, grooms, follows the cursor; naps after a few quiet minutes
  • Listening ears up; the message appears in a bubble
  • Thinking looks up, thought bubble
  • Working types on a tiny laptop; the bubble names the tool
  • Replying talks; the answer appears in a bubble
  • Done hops with sparkles
  • Error puffs up, ears flat, hisses

She idles like a cat: grooming, yawning, chasing a butterfly, sitting in her box. Poke her mid-task and she says she’s busy. Sound is off in this embed — the full demo lets you turn on the synthesised 8-bit meows, purrs and hisses. The room is pixel art drawn in code.
